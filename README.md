## 🎯 프로젝트 개요

Funding Service는 **실물자산 공모**와 **투자 모집**을 관리하는 핵심 서비스입니다.

### 🌟 주요 특징

- **공모 관리**: 새로운 자산 공모 등록 및 관리
- **투자 모집**: 공모 참여자 모집 및 투자 처리
- **동시성 제어**: 대량 투자 요청 안전 처리
- **자동 상태 전환**: Spring Batch를 통한 공모 상태 관리
- **찜하기 기능**: 관심 공모 상품 관리

### 🏆 핵심 역할

- **공모 생성**: 새로운 공모 상품 등록
- **투자 처리**: 공모 참여 및 투자 금액 관리
- **상태 관리**: 공모 진행 상태 자동 전환
- **투자자 관리**: 공모 참여자 정보 관리

## 🛠️ 기술 스택

### Backend
- **Java 17** - OpenJDK LTS 버전
- **Spring Boot 3.5.0** - 최신 Spring Boot 프레임워크
- **Spring Batch 5.0** - 배치 처리 및 스케줄링
- **Spring Data JPA** - ORM 및 데이터 접근 계층
- **Spring Web** - RESTful API 구현

### Database & Cache
- **MySQL 8.0** - 메인 데이터베이스
- **Redis 7.0** - 캐시 및 분산 락
- **HikariCP** - 커넥션 풀 관리

### Message Queue
- **Apache Kafka** - 이벤트 기반 통신
- **Spring Cloud Stream** - 스트림 처리

### Service Discovery & Documentation
- **Netflix Eureka Client** - 서비스 디스커버리
- **OpenFeign** - 서비스 간 HTTP 통신
- **SpringDoc OpenAPI 3** - API 문서화

## 🚀 주요 기능

### 1. 공모 등록
- **상품 정보 검증**: 유효한 상품에 대해서만 공모 등록
- **공모 생성**: 목표 금액, 기간 등 공모 조건 설정
- **이벤트 발행**: 다른 서비스에 공모 생성 알림

### 2. 공모 참여
- **동시성 제어**: Redis 락을 통한 안전한 투자 처리
- **공모 상태 검증**: 활성 상태의 공모만 참여 가능
- **투자 금액 검증**: 최소/최대 투자 금액 확인
- **목표 달성 확인**: 목표 금액 달성 시 자동 완료 처리

### 3. 찜하기 기능
- **관심 공모 등록**: 사용자별 관심 공모 상품 관리
- **찜 목록 조회**: 사용자가 찜한 공모 목록 제공
- **알림 연동**: 찜한 공모의 상태 변경 시 알림

### 4. 공모 상태 조회
- **실시간 현황**: 현재 모집 금액 및 참여자 수
- **진행률 계산**: 목표 대비 달성률 표시
- **상태 정보**: 공모 진행 상태 및 남은 시간

## ⚙️ 환경 설정

### 필수 요구사항
- Java 17 이상
- MySQL 8.0 이상
- Redis 7.0 이상
- Docker (선택사항)

### 환경 변수
- **DATABASE_URL**: MySQL 데이터베이스 연결 정보
- **REDIS_URL**: Redis 서버 연결 정보
- **KAFKA_BOOTSTRAP_SERVERS**: Kafka 서버 정보
- **EUREKA_CLIENT_SERVICE_URL**: Eureka 서버 정보

## 📚 API 문서

### Swagger UI 접속
API 문서는 Swagger UI를 통해 확인할 수 있습니다.

### 주요 API 엔드포인트

#### 공모 관리
- **공모 생성**: 새로운 공모 상품 등록
- **공모 목록 조회**: 현재 진행 중인 공모 목록
- **공모 상세 조회**: 특정 공모의 상세 정보
- **공모 정보 수정**: 공모 조건 및 정보 업데이트
- **공모 삭제**: 공모 등록 취소

#### 공모 참여
- **공모 참여**: 특정 공모에 투자 참여
- **참여자 목록**: 공모 참여자 정보 조회
- **공모 상태 조회**: 현재 공모 진행 상황

#### 찜하기
- **찜하기 추가**: 관심 공모 상품 등록
- **찜하기 제거**: 찜한 공모 삭제
- **찜한 공모 목록**: 사용자별 찜한 공모 목록

## 🔧 주요 설정

### 동시성 제어 설정
Redis를 통한 분산 락으로 대량 투자 요청을 안전하게 처리합니다.

### 배치 처리 설정
Spring Batch를 통한 공모 상태 자동 전환 시스템이 구성되어 있습니다.

### 메시지 큐 설정
Kafka를 통한 이벤트 기반 통신으로 다른 서비스와 연동됩니다.
